# App: Nixie Clock Companion

The same content comes in three forms. Pick whichever suits you; they all show the same build guide.

| Form | Where | Works offline | Talks to the clock over USB |
|---|---|---|---|
| **Website** | GitHub Pages: `https://<owner>.github.io/nixie-clock/` | After the first visit (installable web app) | Yes, in Chrome or Edge on a desktop computer |
| **Installable web app** | Open the website in Chrome or Edge, then *Install* (the icon in the address bar) or *Add to Home screen* on a phone | Yes | Desktop Chrome and Edge only |
| **Desktop app** | The repository's *Releases* page: Windows `.exe` (installer or portable), macOS `.dmg`, Linux `.AppImage` or `.deb` | Yes, fully | Yes, on all three |

## What the app adds

- **[Tools](tools.html)**: a live calculator for tube current, resistor power, converter load and discharge time, using the same formulas as [Equations](EQUATIONS.md). Its results are a model, not measurements.
- **Serial companion**: connects to the clock's Arduino Nano at 115200 baud and sends the firmware's own commands: `STATUS`, set the clock from your computer's time, 12/24-hour, sleep window, `EXERCISE`, `RUN`, a large **HV OFF** button, and `CLEARFAULT`, which only works after you tick "I measured TP4 below 10 V and fixed the cause". It sends nothing the firmware does not already accept from the Arduino serial monitor.
- Every page of the build guide, the schematic PDF, the print plates and the acrylic DXF, available offline.

> **Safety is unchanged.** The USB port is under the bottom cover. Follow [SAFETY.md](SAFETY.md#usb-the-shunt-and-the-serial-monitor): connect USB before 12 V, and treat the HV rail as live until you have measured TP4. Connecting resets the Nano, and the firmware keeps any HV fault latched across that reset.

## Installing the desktop app

The builds are **not code-signed** (signing certificates cost money and Rev C is a prototype), so your operating system will warn you the first time:

- **Windows:** *Windows protected your PC* → *More info* → *Run anyway*. The portable `.exe` needs no install.
- **macOS:** right-click the app → *Open* → *Open*. If macOS still refuses, run `xattr -dr com.apple.quarantine "/Applications/Nixie Clock Companion.app"`.
- **Linux:** `chmod +x NixieClockCompanion-*.AppImage` then run it, or `sudo apt install ./NixieClockCompanion-*.deb`. For USB serial access, add yourself to the `dialout` group once: `sudo usermod -aG dialout $USER`, then log out and back in.
- **Windows Subsystem for Linux (WSL):** run the Windows build instead. WSL cannot see USB serial ports without extra tools.

Each release lists SHA-256 checksums so you can verify the download (see [SECURITY.md](SECURITY.md#signed-releases)).

## How it is built

- `app/` is a small Electron app: `main.js` opens the prebuilt `site/` folder (copied into `app/www` by `copy-site.js`), keeps pages sandboxed with no Node.js access, opens every web link in your normal browser, and picks the Nano's USB serial port automatically (Arduino, CH340, FTDI or CP210x adapters, else the first port).
- Versions are pinned in `app/package.json` and `app/package-lock.json`. Dependabot proposes updates.
- Pushing a tag named `app-vX.Y.Z` runs `.github/workflows/desktop.yml`, which builds on Windows, macOS and Linux runners and attaches the files to a GitHub Release. `scripts/release_app.sh` does the version bump, tag and push for you ([DEVELOP.md](DEVELOP.md)).
- The installable web app comes from `site/manifest.webmanifest` and `site/sw.js`, both generated by `scripts/build_site.py`.
