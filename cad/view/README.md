# View-only assemblies

Open these `.stl` files on GitHub to rotate the whole clock in 3D. **Do not print them**: they contain the glass, PCB, switch, window, wood and brass parts in assembly coordinates. The heirloom view is the finished clock; the printed-edition view is the inner case on its own; the chassis view shows the inside with the case lifted off. Printable parts are in `../stl/` and `../print/`.
